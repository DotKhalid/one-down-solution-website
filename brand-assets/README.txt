OneDown Solution brand pack

Business card
- 3.5 x 2 inches, 300 DPI (1050 x 600 pixels).
- business-card-print.pdf contains front and back as two pages.
- PNG and JPG versions are provided for each side.
- The PDF has no bleed. Ask the print shop to add bleed if required.

Logo
- onedown-logo.svg and onedown-logo.png have transparent backgrounds.
- onedown-logo.jpg is on white; onedown-logo-white.jpg is on deep teal.
- onedown-logo-white.svg is the editable white-text vector version.
- onedown-icon.png and onedown-icon.jpg are square mark exports.

The card uses the supplied contact name and phone number. No email, street
address, or public website URL was provided, so none has been invented.

To regenerate the raster exports, install Pillow and run:
  python create_assets.py
